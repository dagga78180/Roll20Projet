# Référence des prédicats — V2

Les prédicats sont des mots-clés lus par COFantasy depuis la fiche ou générés par CoFItem. Un prédicat booléen peut être écrit seul ; une valeur se note généralement `nom:valeur`. Certaines familles utilisent plusieurs segments (ex. `bonus_RD::feu:2`).

## Règles de saisie

- Un prédicat par espace ou ligne ; les commentaires de fiche peuvent utiliser `//`.
- Les noms sont sensibles à la convention du moteur : recopier l’identifiant exact.
- Les préfixes terminés par `_` sont des familles paramétrées, par exemple `bonusTests_...`, `bonusSaveContre_...` ou `diviseEffet_...`.
- Les prédicats d’objet ne s’appliquent que dans le contexte où CoFItem les injecte (porté, équipé, arme active, etc.).
